# R3 — Shared navigation and design system

Baseline: accepted R2 merge `31aaffacd28b5d8da21ab0aac2e84d3b50b0296a`.
Structured Workspace — Option A is the accepted direction. This milestone
applies its shared visual language; R4 route workflow redesign is not included.

This document records the original R3 delivery. The later Viewer/Query layout
closure, after accepted R4, is documented in [R3_VISUAL_CLOSURE.md](R3_VISUAL_CLOSURE.md).
Its persistent desktop rail, compact chart and mobile cards/sheets supersede the
original Viewer presentation described below; shared navigation/theme contracts remain.

## Shared presentation

The navy header uses one Home / BOQ Viewer / Query / Report / Media navigation
definition. Logo returns Home. Active links expose `aria-current="page"`.
Desktop navigation starts at 1024px; smaller widths use a native modal dialog.
Public navigation has no account actions. Authenticated mode retains Login or
Logout as appropriate; server authorization and privileged routes are unchanged.
The obsolete header Contact destination is removed from shared navigation.

The drawer supports keyboard entry, Tab/Shift+Tab containment, Escape, close
button and backdrop dismissal. The modal makes underlying content inert.
Closing returns focus to the menu trigger when it is visible; desktop resize
closes the drawer and restores body scrolling. Closed dialog links are excluded
from keyboard navigation. A skip link targets the content wrapper.

Shared CSS in `app/globals.css` defines navy identity, blue actions, semantic
text/status colors, quiet light/dark surfaces, borders, 8px spacing basis,
8px controls and 12px panels. Existing local Sarabun fonts serve Thai and English;
no external font service or dependency is introduced. Controls have a 44px minimum
height, visible focus, disabled appearance and consistent input treatment.
Tables retain all columns, data semantics and pagination. Scroll regions are
keyboard focusable. Long descriptions/filenames wrap; numeric Report totals stay
together. At wide desktop sizes the existing Viewer WBS panel sits beside the
existing chart/table content. Smaller layouts stack it above the results.

BOQ and Report share a SourcePanel presentation and control classes. Their
workbook ownership remains separate. Report behavior and all business copy,
calculation, cutoff and snapshot semantics remain as R1/R2; no R4 workflow
redesign is implied. Home imagery/content and Media playlist remain.

## Theme contract

Color theme choices are System, Light and Dark. Without an explicit saved choice,
System follows `prefers-color-scheme`, including live changes. Explicit choices
persist under the existing `okmd_theme_mode` key and override the OS. Returning
to System persists that choice. Storage events synchronize preference between
tabs, but do not share workbook state. Invalid saved values fall back to System.
Blocked storage leaves an operational in-memory choice.

The early inline script applies the same resolution before hydration; the client
provider applies subsequent changes. The previous competing Zustand persistence
key is no longer written. This change stores theme preference only, never files.

## Engineering verification

Run from a clean baseline plus this delta, without secret environment files:

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm lint
OKD_ACCESS_MODE=public NEXT_TELEMETRY_DISABLED=1 pnpm build
pnpm exec playwright install chromium
pnpm test:browser
```

An installed compatible browser can be selected with `TEST_CHROMIUM_PATH`.
Browser suites own ports 3187, 3190 and 3193. R3 checks all five pages in light/dark
at 360, 390, 768 and 1440px; active route semantics, loaded-workbook layouts,
page overflow, theme changes/reload/blocked storage, drawer keyboard containment,
focus return and session retention through Home/Report/Media. It measures semantic
text and action token contrast at >=4.5:1. This is not a claim that every pixel,
chart series or imagery overlay has a complete WCAG audit.

```sh
OKD_ACCESS_MODE=authenticated NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:43999 NEXT_PUBLIC_SUPABASE_ANON_KEY=synthetic-test-anon pnpm build
node tests/auth-smoke.cjs
OKD_ACCESS_MODE=public NEXT_TELEMETRY_DISABLED=1 pnpm build
```

Final public rebuild must run without Supabase variables. Toolchain and exact
executed results accompany the R3 report. No dependency or lockfile changes.
Existing R1 security deferrals and input-resource limitations remain.

## Acceptance boundary

Headless Chromium evidence is not native Windows/macOS/phone or Safari acceptance.
No deployment, live account/RLS test or external YouTube playback acceptance
is claimed. Coordinator reviews engineering evidence first; PO desktop acceptance
is limited to shared navigation/responsive layout, theme/readability and the
existing Viewer/Query workflow. Git integration remains Coordinator-owned after
PO acceptance.
