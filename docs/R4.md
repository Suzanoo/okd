## Verified behavior and boundaries

Home is tool-first: Viewer, Query, Report and Media link to existing routes.
All seven existing illustrations remain. Fixed project progress percentages,
unverified project news and stakeholder-login claims are no longer rendered.
Illustrations are explicitly not current project evidence.

Report still automatically loads the synthetic sample on entry. Its source name
appears only after successful parsing. While loading, previous data is named and
period/cutoff controls are paused; selecting a newer upload remains possible.
Initial failure shows no fabricated KPI. Failed replacement retains the previous
named source and cutoff. Select a corrected workbook to retry; the sample can
also be downloaded and selected. Existing latest-request protection remains.
Report is separate from the shared BOQ session and clears on leaving Report.

The download is labeled **Download synthetic sample** and still points to
`/data/example_progress.xlsx`, never the uploaded workbook. Required sheets,
saved formula values and the 20 MiB limit are stated beside the controls.
Existing parser validation, formula-cache requirements and snapshot freshness
rules remain in [R1](R1.md). No new workbook schema or formula evaluator exists.

Progress variance is signed Actual minus Plan in percentage points (pp).
Progress status says above/below/matches Plan, not schedule delay. The signed
duration proxy keeps the exact existing rounded numeric result. It is not a
critical-path or confirmed delay assessment. Weekly/monthly latest-observation,
cutoff reset and Actual masking behavior are unchanged. Zero Actual is valid;
missing Actual is unavailable. A withheld/absent activity snapshot is explicitly
not zero progress. Live chart data may remain available while a snapshot is
withheld. The full activity table is keyboard-scrollable.

Media retains the same playlist ID and privacy-enhanced YouTube iframe.
Loading, empty configuration, timeout/error and keyboard retry states are
available. The external playlist link remains available during failure.
An iframe load event confirms only the frame, not successful video playback:
cross-origin provider errors, restrictions and deleted videos cannot all be
detected from the parent. The UI states that limitation instead of claiming
playback success. No provider API, account or media CMS was added.

Query reports CSV/PDF preparation errors and retry actions. PDF font HTTP/empty
responses now fail explicitly; failed requests are not cached. Success means
download requested, not proof that a file was saved to disk. Existing export
content, Thai font, 2,000-row PDF limit, CSV scope and stale-source protection
remain. Empty matches explain search/filter recovery. Existing BOQ source,
loading/error/refresh feedback and Viewer/Query shared session are preserved.

## Reusable engineering notes (avoid repeating setup failures)

1. Verify the supplied commit through read-only repository metadata and download
   its source archive. Wait for download/extraction completion before inspecting
   paths. Do not assume transient files from earlier sessions still exist.
2. Read README and milestone runbooks, then actual implementation/tests. Keep
   source and private reference inputs separate. Work performs no Git operations.
3. Reuse the lockfile and existing suites. Do not upgrade dependencies merely
   because a package manager prints an update notice.
4. Build and browser-test sequentially. Never rebuild `.next` while a browser
   suite is serving it. Tests own their server in the same process environment.
5. Check the browser executable before testing. In this environment the restored
   browser crashed with exit 139; a fresh Chrome for Testing 134.0.6998.35 worked.
   This is test-environment evidence, not a recommended production browser pin.
6. Use accessible labels for selects (theme adds another select). Scope alerts
   to `main` because Next has a route announcer. Install dialog/download listeners
   before clicking. Wait for drawer close events and chart/font layout settling.
7. Fault-inject local sample/font/network failures and use synthetic workbook
   fixtures. Iframe load is not evidence of real video playback.
8. Compare final files byte-for-byte with the exact baseline archive; package
   only changed source, explicit documentation and test evidence. Exclude private
   workbooks, secrets, dependencies, caches and internal screenshots. Verify every
   manifest hash and reconstructed candidate before handing off one ZIP.
